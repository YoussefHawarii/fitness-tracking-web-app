# Workout exercises come from a fixed catalog, not free text

When designing Workout logging, we considered letting users type their own exercise names, since no curated list can cover every gym's equipment or every user's preferred name for a movement. We chose a fixed, curated catalog instead, with each Workout exercise assigned to exactly one primary Muscle group (see `CONTEXT.md`). Both the "last time I did this" inline comparison and History filtering depend on matching today's entry to a past one by exact exercise identity — free text can't guarantee that (e.g. "Lat Pulldown" vs "lat pull down" vs "Wide Grip Pulldown" would silently fragment a user's history). A user-added custom exercise, and/or multi-Muscle-group tagging for movements that work more than one group (e.g. Push-Ups), are plausible future additions once the fixed catalog proves too limiting in practice.
