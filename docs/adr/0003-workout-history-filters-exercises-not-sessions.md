# Workout History filtering shows only the matching exercises, not the whole session

When a Workout is tagged with multiple Muscle groups (e.g. Chest + Triceps) and the user filters History by one of them, we considered showing the entire session for context, since the session as a whole matches the filter. We chose instead to show only the Workout exercises belonging to the filtered Muscle group, hiding the rest. This was a deliberate reversal of our initial recommendation, made explicitly by the product owner: the same Workout can render differently depending on which Muscle group filter is active — a session card is not a fixed, complete view of everything trained that day once a filter is applied. Only the unfiltered History view (or the session's own edit view) shows a Workout in full.
